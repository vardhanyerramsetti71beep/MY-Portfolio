## 🛠️ Local Development & Production Build

```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server (port 3000)
npm run dev

# 3. Compile optimized production build (into /dist)
npm run build

# 4. Preview local production bundle
npm run preview
```
